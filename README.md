# 🤖 Фунт 2.0 - Telegram Bot

**Язвительный, злобный, но честный бот на основе DeepSeek AI**

Простая и эффективная версия с управлением контекстом, проактивностью и умной системой подколов.

---

## 🚀 Быстрый старт

### 1. Убедитесь, что виртуальное окружение активно
```bash
source myenv/bin/activate  # На macOS/Linux
# или
myenv\Scripts\activate  # На Windows
```

### 2. Запустите бота
```bash
./start_bot.sh
```

Или напрямую:
```bash
python Funt_2.0.py
```

### 3. Остановите бота
```bash
./stop_bot.sh
```

---

## 🎮 Команды бота

```
/start - Начать работу с ботом
/help - Показать справку
/stats - Статистика работы (сообщения, API вызовы, шутки)
/context - Показать текущий контекст (последние 10 сообщений)
/clear - Очистить контекст и историю шуток
```

### Примеры использования

**Посмотреть статистику:**
```
/stats
```
Покажет:
- ⏱ Время работы бота
- 💬 Количество сообщений (всего, от пользователей, от бота, проактивных)
- 🤖 API вызовы и ошибки
- 😂 Использованные шутки

**Посмотреть контекст:**
```
/context
```
Покажет последние 10 сообщений, которые бот помнит.

**Сбросить контекст:**
```
/clear
```
Очистит память бота - полезно, если бот зациклился на одной теме.

## 🎯 Ключевые возможности

### ✅ Умная память
- Помнит последние 20 сообщений
- Понимает контекст разговора
- Ловит на противоречиях

### ✅ Не повторяется
- Отслеживает использованные шутки
- Не использует одну и ту же подколку дважды
- Выбирает разные векторы атаки

### ✅ Проактивность (2 типа)
1. **Вброс новостей**: Комментирует новости с УНИАН (6 раз в день)
2. **Инициирование разговоров**: Сам начинает разговор с конкретными людьми (каждые 2 часа)

### ✅ Адаптивное поведение
- 15-20% шанс игнорировать тему и просто подколоть
- Распознает вариации имен (@doom4a, Дум, Думчик → Дмитрий Садовой)
- Использует персональные слабости каждого друга

### ✅ Естественный стиль
- Короткие, резкие фразы
- Гиперболы и сарказм
- Язвительность и злоба
- Качество важнее количества слов

## 🐛 Решение проблем

### Проблема: Бот не отвечает
**Решение:**
1. Проверь, что API ключи корректны в `.env`
2. Проверь логи: `tail -f funt_2.0.log`
3. Убедись, что бот запущен: `./start_bot.sh`

### Проблема: "Token is invalid"
**Решение:**
- Проверь `TELEGRAM_TOKEN` в `.env`
- Получи новый токен у @BotFather

### Проблема: "API key not valid"
**Решение:**
- Проверь `DEEPSEEK_API_KEY` в `.env`
- Убедись, что на аккаунте есть credits

### Проблема: Бот повторяет шутки
**Решение:**
- Используй `/clear` чтобы сбросить историю
- Увеличь `MAX_HISTORY` в коде

### Проблема: Проактивные сообщения не работают
**Решение:**
1. Напиши боту хотя бы одно сообщение
2. Подожди настроенное время (2 часа для инициирования разговоров)
3. Проверь логи: должно быть "Инициирован разговор..."
