# Changelog - Фунт 2.0

## Последние обновления (сегодня)

### ✨ Добавлены команды бота
Теперь бот поддерживает следующие команды:
- `/start` - Приветствие и список команд
- `/help` - Подробная справка о работе бота
- `/stats` - Статистика работы (время работы, сообщения, API вызовы, шутки)
- `/context` - Показать последние 10 сообщений из контекста
- `/clear` - Очистить контекст и историю использованных шуток

### 📊 Добавлена система метрик
Бот теперь собирает и отслеживает:
- Время работы (uptime)
- Общее количество сообщений
- Сообщения от пользователей / от бота
- Проактивные сообщения
- API вызовы и ошибки
- Использованные шутки

### 🎯 Улучшена обработка ошибок
- Трекинг ошибок API в метриках
- Безопасная обработка отсутствующих полей в сообщениях
- Улучшенное логирование с emojis

### 🔧 Техническая часть
- Полная интеграция метрик во все функции (post_news, initiate_conversation, handle_msg, generate_funt_response)
- Регистрация command handlers
- Улучшенный вывод при запуске бота
- Сохранение простой архитектуры (без классов, без config.py, без баз данных)

### 🎨 Улучшения UX
- Информативные сообщения команд
- Форматированная статистика с эмодзи
- Ограничение длины вывода контекста (4000 символов)
- Красивый логированный старт бота

## Что уже было раньше

### 🧠 Структурированный промпт
- CRITICAL RULE про идентичность (никогда не раскрывать, что бот - это AI)
- `<CORE_PERSONA>` - подробный профиль персонажа
- `<KNOWLEDGE_BASE>` - таблицы User Dossier и Anecdote Database
- `<STYLISTIC_ENGINE>` - правила стиля общения
- `<OPERATING_LOGIC>` - логика ответов с Маршрутизатором Насмешек

### 🤖 Проактивность
- Вбросы новостей с Unian.net (6 раз в день в случайное время)
- Инициирование разговоров с конкретными людьми (каждые 2 часа)
- Динамическая генерация подколок через DeepSeek API

### 🎯 DeepSeek API
- Использование deepseek-chat модели
- Temperature 0.9 для креативности
- Контекст последних 10 сообщений

## Как использовать новые фичи

### Посмотреть статистику:
```
/stats
```

### Посмотреть текущий контекст:
```
/context
```

### Сбросить контекст (если бот зациклился):
```
/clear
```

### Получить справку:
```
/help
```
